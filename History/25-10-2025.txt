# Details

- for now the collision system has:
    * m is number of occupied cells
    * n is number of collision object
    * p is number of potential pairs (p = (c * (c - 1)) / 2, c is number of collision objects in a cell)
    . for each board update:
        . Best O(m), Average O(m), Worst O(mn)
    . for each pairs computations
        . Best O(p), Average O(p), Worst O(pn)
    . in total, for each frame (update + compute):
        . Best O(m + p), Average O(m + p), Worst O((m + p) * n)
